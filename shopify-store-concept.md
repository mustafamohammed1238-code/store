# Collection Page Strategy
- **Filters:** Price, case size, strap material, movement type, color, water resistance, availability.
- **Sorting:** Featured, Best Selling, Newest, Price low-high/high-low, Customer rating.
- **Merchandising layout:**
  - Desktop: 3–4 column grid; mobile: 2-column with sticky filter/sort bar.
  - First row blends hero collection tile + top SKUs.
  - Quick add for accessories; “View Details” for watches.
- **Badge strategy:**
  - **New:** first 14 days
  - **Best Seller:** top sales percentile
  - **Limited:** capped units
  - **Low Stock:** inventory threshold-based
- **Collection intro copy guidance:**
  - 1 short premium paragraph (40–70 words).
  - Mention use case + materials + fit/occasion.
  - Include one internal link to related collection.

# Product Page Strategy
- **Image gallery guidance:**
  - 6–10 assets: front, side, wrist shot, clasp/caseback macro, lifestyle, packaging.
  - Zoom-enabled; video or 360 spin preferred.
- **Product title/subtitle structure:**
  - Title: Model name
  - Subtitle: Movement + key material + style tag (e.g., “Automatic • Sapphire Crystal • 40mm”).
- **Pricing and promo treatment:**
  - Clear price, optional compare-at price, installment messaging, and limited-time promo line.
- **Product description structure:**
  1. One-line value summary
  2. 2 short paragraphs (design story + wear context)
  3. Scannable highlights
- **Feature bullets:**
  - Movement type
  - Case size/thickness
  - Crystal type
  - Strap material/width
  - Water resistance
  - Included accessories
- **Specs block:**
  - Structured table for technical detail and compatibility.
- **Shipping/returns block:**
  - Delivery windows by region, return period, exchange policy.
- **Warranty/reassurance messaging:**
  - Clear duration + coverage + claim process link.
- **Reviews placement:**
  - Star summary near price; full reviews below product details.
- **Related products:**
  - “Complete the Look” (strap + roll), “You May Also Like” (similar watches).
- **Sticky add-to-cart suggestions:**
  - Mobile sticky bar with price, variant selector, ATC button.
  - Desktop sticky ATC after scrolling beyond gallery.

# Design Direction
- **Color palette (example):**
  - Obsidian `#111111`
  - Ivory `#F7F5F2`
  - Graphite `#2C2C2C`
  - Champagne accent `#C9A66B`
  - Cool gray `#D9DDE2`
- **Typography pairing:**
  - Headings: Elegant serif (e.g., Cormorant Garamond / Canela-style alternative)
  - Body/UI: Modern sans (e.g., Inter / Neue Haas Grotesk-style alternative)
- **Spacing style:** Generous whitespace, 8px spacing system, large section rhythm.
- **Button style:** Solid primary, ghost secondary, medium corner radius (6–8px).
- **Card style:** Subtle border, minimal shadow, tight typography hierarchy.
- **Icon style:** Thin-line monochrome icons.
- **Imagery direction:** High-contrast product macros + understated lifestyle scenes; avoid cluttered backgrounds.
- **Luxury ecommerce mood keywords:** Precision, restraint, tactile, modern heirloom, confidence.

# Shopify Build Notes
- **Recommended theme style direction:** Premium OS 2.0 theme with flexible sections (e.g., Prestige/Impulse-style capabilities), adapted to original brand identity.
- **Section architecture:**
  - Reusable sections for hero, collection cards, product carousel, trust icons, testimonials, FAQs, newsletter.
  - Metafields for specs, movement, warranty, and material details.
- **App needs (if relevant):**
  - Reviews app (photo/video UGC)
  - Wishlist app
  - Advanced filter/search app (if catalog grows)
  - Email/SMS capture automation
  - Bundles/cross-sell app
- **SEO basics:**
  - Keyworded collection titles, unique product meta titles/descriptions, schema (Product/Review/FAQ), optimized alt text.
- **Speed/performance:**
  - WebP images, lazy loading below fold, minimal app bloat, defer non-critical scripts.
- **Mobile UX priorities:**
  - Sticky ATC, thumb-friendly filters, compressed copy blocks, fast-loading media, one-page checkout clarity.

# Inspiration Summary
From the reference, the most useful takeaways are the premium-first hierarchy (strong hero → collections → featured products), clear navigation, and trust-forward ecommerce structure. This concept improves on that pattern by prioritizing stronger mobile conversion mechanics (sticky ATC, filter UX), more explicit specs/warranty storytelling, and clearer cross-sell architecture for watches plus accessories. The result is deliberately original in brand language, visual direction, and content framework while preserving proven luxury ecommerce UX principles for Shopify.
